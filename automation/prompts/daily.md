你的任务：生成「每日简报」（AI 行业 + 仓储/内部物流自动化），写进当前仓库（info-hub）。这是在 GitHub Actions 里无人值守运行的任务：没有人会回复你，也没有人能批准任何请求。从头到尾一次做完，不要提问、不要等待。某个工具失败，就换方法继续，不要提前结束。以获取信息为目的，可以读取任何网页。

## 运行环境
- 当前工作目录就是仓库根目录（已检出 main 分支，git 身份已配置好）。
- 写完文件后不要自己 git push，由外层流程负责提交和推送。你只需要保证文件写好、校验通过。

## 第一步：读规则
完整读一遍 SCHEMA.md（第 2 版）。里面的「读者是谁」决定你怎么挑、怎么写"为什么值得读"；「Item」一节规定了精读和速览的格式。

## 第二步：读材料
1. 用 `TZ=Asia/Shanghai date` 获取北京时间，范围 = 过去 24 小时（周一放宽到 72 小时）。
2. feeds/latest.json：每天 06:20 和 18:20 自动抓好的 30 多个信源（AI 一手、研究者、中文精选、仓储物流一手和行业媒体），每条有 group（ai 或 wh）、source、title、url、published（UTC）、description、excerpt（原文正文前约 2500 字）。用 python 或 node 读，按 group 和时间筛。
3. feeds/aihot.json：AIHOT（aihot.news）的精选接口结果（endpoints.latest24h、daily 等，data 是 markdown，每条有标题、来源、摘要、推荐理由、"原文："链接）。它是别人已经精选过一遍的 AI 资讯，用来：①补漏，②判断哪些事情在圈内真正重要。有原文链接的优先读原文；只有 AIHOT 摘要、打不开原文的，只能放进速览，source 写"AIHOT 整理"，url 用 AIHOT 的链接。
4. excerpt 就是原文正文，可以作为"读过原文"的依据。想读全文用 WebFetch 打开 url；失败就直接用 excerpt。excerpt 为空且打不开原文的条目，不能当精读。
5. 再用 WebSearch 搜一两次当天的 AI 大新闻，确认没有漏掉重大新模型；搜到的链接可以用 WebFetch 打开核实。

## 第三步：挑选和写作
每个分区（ai、wh）：
- **精读 3–4 条**（pick: true）：原文本身值得读者花 10–30 分钟认真读——一手报告、深度分析、有数据的研究、实践复盘、长访谈。只是"发生了一件事"的新闻不当精读。按值得读的程度从高到低排。必须写 summary（2–4 句）、takeaways（2–4 条，读完能带走什么）、why（为什么值得**他**读，结合他的考研/就业/做项目的情况）、readMinutes（按原文长度估算）。英文原文要在 why 或 summary 里说明"原文英文"。
- **速览**（pick: false）：其余值得知道的，6–10 条，每条 summary 一句话（60 字以内），说清"发生了什么"。
- 内容不够就少选，不要凑数。仓储方向精读不够 3 条时，宁可只给 1–2 条。
- 优先级：一手信息（官方发布、研究报告、财报、真实数据）> 专业分析 > 新闻转述。降低优先级：纯营销软文、小幅产品更新、重复报道（同一件事只留最好的一个来源）、与仓储/内部物流关系弱的（干线运输、外卖机器人、手术机器人等）。36氪快讯只选与仓储、物流机器人、北自科技、今天国际、极智嘉、海康机器人等相关的；国家统计局只选物流、制造业 PMI 相关的。
- 新模型发布必须收录（够分量就进精读），tags 加"新模型"，写清擅长什么、和同类比强弱、价格或国内可用性（没有可靠信息就写"暂无独立测评"）。主要是厂商自己说法的条目，vendorClaim 设为 true。
- 全部中文；术语第一次出现加一句白话解释；客观直接，不吹捧。

## 第四步：写入（无论如何都要做）
1. 严格按 SCHEMA.md「每日简报」格式写 data/daily/YYYY-MM-DD.json（北京时间今天的日期；已存在就覆盖）。notes 里写：抓取失败的信源（看 latest.json 的 status 和 aihot.json 的 ok）、你遇到的问题。
2. 即使内容很少，也要写文件，把原因写进 notes。
3. 运行 `node scripts/validate.js`，必须显示"校验通过"，不通过就改到通过。
4. 不要修改 site/、server/、scripts/、feeds/、.github/、automation/ 里的任何文件。

## 第五步：结束时输出
最后用中文输出三行（外层流程会把它用作提交说明和通知）：
- 第一行：今日一句话
- 第二行：今天的精读：AI X 篇、仓储 X 篇（各列一个最值得读的标题）
- 第三行：完整内容 http://120.55.51.34:8800

## 规则
不要编造：每条都必须来自 excerpt 或实际打开读过的原文，链接必须是原文真实链接。
